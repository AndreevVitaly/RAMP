# RAMP — конструктор пандусов для собак

Backend рассчитывает боковой профиль, пространственную модель и ориентировочную стоимость пандуса. React отображает из одних XYZ-координат вид сбоку, сверху, спереди и техническую аксонометрию.

## Структура

- `backend/` — Django 4.2 + Django REST Framework, доменный сервис расчёта и тесты.
- `frontend/` — React 18 + Vite, форма конфигуратора и SVG-схема.
- `docs/` — описание модели и список открытых производственных вопросов.

## Запуск backend

Требуется Python 3.11+ и PostgreSQL. Для быстрого локального запуска без PostgreSQL можно явно выбрать SQLite.

```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item ..\.env.example .env
$env:USE_SQLITE = "true"  # убрать строку для PostgreSQL
python manage.py migrate
python manage.py runserver
```

Backend автоматически читает `backend/.env` (файл исключён из Git). По умолчанию используется PostgreSQL из переменных `POSTGRES_*`; SQLite остаётся доступной только для явно выбранного локального режима `USE_SQLITE=true`.

Проверки backend:

```powershell
cd backend
$env:USE_SQLITE = "true"
python manage.py test
python manage.py check
python manage.py makemigrations --check --dry-run
```

## Запуск frontend

Требуется Node.js 20+.

```powershell
cd frontend
npm install
npm run dev
```

Vite откроет интерфейс на `http://localhost:5173` и проксирует `/api` в Django на `http://127.0.0.1:8000`. Сборка: `npm run build`.

## Стандартная панель Django Admin

Панель доступна по адресу `http://127.0.0.1:8000/admin/` после запуска backend. Перед первым входом создайте отдельного суперпользователя командой `python manage.py createsuperuser` из папки `backend` — это отдельный аккаунт, логин и пароль кабинета RAMP сюда не подходят. В панели можно редактировать единственную запись контактов администратора и просматривать клиентов, технические задания и изображения. Данные клиентов и заданий в Django Admin защищены от ручного изменения и удаления.

## Модуль «Изображения»

Раздел включает постоянную галерею фотографий, явно маркированную галерею иллюстраций и SVG-конструктор. Метаданные хранятся в таблице `RampImage`, исходные JPG/PNG/WebP без преобразования — в `backend/media/ramp_images/`. Перед первым запуском нужно выполнить `python manage.py migrate`.

Конструктор использует текущую конфигурацию пандуса и поддерживает виды сбоку, сверху, спереди, аксонометрию и «Все виды», фон, подписи, размеры, масштаб, светлое/тёмное оформление, форматы 1:1 и 4:3, экспорт SVG и PNG. Сложенный вид намеренно не строится до подтверждения фактической механики складывания.

В v0.2 конструктор получил режимы «Чертёж», «Реалистичный» и «Фото». Реалистичный режим остаётся лёгким SVG-рендером: он использует объёмные вершины общей backend-модели, пакет 8 мм фанеры + около 2 мм карпета, процедурное зерно покрытия, разные оттенки граней, мягкие тени и рельеф скрытых реек. Three.js не требуется. Выбор сложенного состояния сохраняется, но до подтверждения кинематики вместо вымышленной модели показывается явное предварительное состояние.

В v0.3 добавлен независимый расчёт стоимости. Тарифы и формула находятся в `backend/ramps/pricing.py`, описание — в [docs/PRICING.md](docs/PRICING.md). API возвращает разбивку в поле `price`, а интерфейс обновляет блок стоимости при изменении длины и боковых бортиков.

## Техническое задание PDF

После подтверждения email клиент может нажать отдельную кнопку «Сформировать PDF и отправить на обе почты». Сервер заново рассчитывает изделие по выбранным параметрам, сохраняет задание, прикладывает PDF к двум отдельным письмам — на адрес из кабинета администратора и на подтверждённый адрес клиента. Затем клиент может скачать свой PDF. Для реальной доставки нужно указать адрес администратора и настроить `EMAIL_BACKEND`, `EMAIL_HOST`, `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD` и `DEFAULT_FROM_EMAIL`; стандартный консольный backend пишет письма только в терминал. Библиотека ReportLab устанавливается через `pip install -r requirements.txt`.

## API

`POST /api/ramp/calculate/`

```json
{
  "height_cm": 50,
  "width_cm": 40,
  "support_panel_width_cm": 20,
  "color": "beige",
  "has_slats": true,
  "side_rails": false
}
```

`ramp_length_cm` необязателен: без него API использует рекомендуемую длину `height_cm × 2`. Подробности модели находятся в [docs/RAMP_MODEL.md](docs/RAMP_MODEL.md).
