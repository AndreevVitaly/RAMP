# Расчёт стоимости RAMP

Ценообразование отделено от геометрии и находится в `backend/ramps/pricing.py`. Тарифы заданы именованными константами:

- минимальная оплачиваемая длина — 60 см;
- базовая цена для 60 см — 1600 ₽;
- каждый дополнительный сантиметр — 10 ₽;
- боковые бортики — 500 ₽;
- поперечные рейки — 0 ₽.

Формула:

```text
base_price = 1600 + (length_cm - 60) × 10
total_price = base_price + (side_rails ? 500 : 0)
```

Промежуточные значения длины поддерживаются без округления до десятков. Для денежных вычислений используется `Decimal`. API возвращает `price` с полями `base_price_rub`, `side_rails_price_rub`, `slats_price_rub` и `total_price_rub`. Высота, ширина, ширина стойки, цвет и наличие реек цену не меняют.

Длина менее 60 см отклоняется до построения конфигурации. Будущие тарифы ширины, материалов, скидок, доставки и индивидуального заказа в текущую формулу не включены.
