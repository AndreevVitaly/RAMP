# Расчётная модель пандуса

## Входные параметры

`height_cm` — вертикальная высота подъёма от пола до верхней точки. Значение должно быть больше нуля.

`ramp_length_cm` — длина наклонной рабочей поверхности, а не её проекция на пол. Если клиент не передал длину, сервис использует рекомендуемое значение:

```text
recommended_length_cm = height_cm × 2
```

Это производственная рекомендация, а не жёсткое ограничение. При такой пропорции угол равен 30°. Пользователь может выбрать другую длину, если она не меньше высоты.

`width_cm` — ширина рабочей поверхности. Стандартное значение — 40 см, но расчёт принимает и нестандартную положительную ширину.

`color` — цвет покрытия. Доступны `dark_gray`, `light_gray`, `black`, `beige`; значение по умолчанию — `dark_gray`.

`side_rails` показывает наличие боковых бортиков. По умолчанию бортики отсутствуют.

## Геометрия

Угол наклона относительно пола рассчитывается в градусах:

```text
angle_deg = degrees(asin(height_cm / ramp_length_cm))
```

Горизонтальная проекция наклонной поверхности:

```text
horizontal_run_cm = sqrt(ramp_length_cm² - height_cm²)
```

Геометрия допустима только при `height_cm > 0`, `ramp_length_cm > 0` и `ramp_length_cm >= height_cm`.

## Поперечные рейки

Первая рейка находится в 5 см от нижнего края наклонной поверхности. Каждая следующая находится через 14 см: `5, 19, 33, 47, …`. В список попадают все позиции, которые не превышают длину рабочей поверхности. Дополнительное ограничение расстояния до верхнего края пока не применяется.

## Пока не определено

Модель намеренно не описывает полную геометрию нижнего основания, крепление высоты, размеры самих реек, материалы, нагрузку и цену. Эти правила должны быть получены от производства; полный список находится в [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md).
